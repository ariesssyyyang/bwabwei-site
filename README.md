# Bwa Bwei — website

Static pages for the Bwa Bwei iPhone app (moon-block divination, 擲筊),
served via GitHub Pages at <https://ariesssyyyang.github.io/bwabwei-site/>.

- `index.html` — landing page
- `privacy.html` — Privacy Policy (linked from App Store Connect)
- `support.html` — Support page (linked from App Store Connect)

Pages are bilingual (繁體中文 first, English below). Plain HTML, no build
step. Edit a file and push; GitHub Pages redeploys.
